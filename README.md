Outside of that I write real code: systems tools, backend servers, and the occasional kernel patch that some poor maintainer had to review at 2 AM.

### 🛠️ Current Campaigns

**🎢 Rec Room Revival Backend**
A from-scratch ASP.NET Core server replacing Photon's networking, built off reverse-engineered IL2CPP binaries and way too many Wireshark captures of UDP traffic. Basically speedrunning "reverse engineer a live multiplayer game" any%.

**📊 SystemPulse**
A C#/.NET + SignalR system monitor, now with Linux support, because Task Manager is for casuals.

**🏗️ ProbookStats / WinStats**
The projects that taught me C# by making me read `/proc` and `/sys` like ancient scrolls, then port the whole thing to Win32 P/Invoke for fun. No regrets. Some regrets.
